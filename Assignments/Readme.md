# University Lecturer Salary Management System

## Description
A Java-based project that manages full-time and part-time lecturers and calculates their salaries.

## Features
- Register lecturers.
- Calculate lecturer salaries.
- Display lecturer information.
- Find the highest-paid lecturer.
- Calculate full-time and part-time payrolls.
- Filter lecturers by salary.

## OOP Concepts
- **Abstraction:** Abstract `Lecturer` class.
- **Encapsulation:** Private fields with getters and setters.
- **Inheritance:** Full-time and part-time lecturer classes.
- **Polymorphism:** Method overriding.
